## 🛠️ 수정하는 방법

1. 위 **📝 페이지 수정** 링크를 누르세요.
2. 내용을 고친 뒤 **Commit changes**를 누르세요.
3. 1~2분 뒤 **🌐 사이트**에서 반영된 내용을 확인하세요.

> [!NOTE]
> 사이트는 **`gh-pages` 브랜치**에서 배포돼요. `main` 브랜치만 고치면 사이트에 반영되지 않아요.
